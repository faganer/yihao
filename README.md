## 用户中心功能

| 模块 | 能力 |
| :--- | :--- |
| 总览 | 查看当前套餐、到期时间、周期用量 |
| 流量记录 | 上传 / 下载分项与每日计费明细 |
| 订阅管理 | 复制、导入或重置订阅链接 |
| 订单 | 核对购买周期、优惠与应付金额 |
| 支持 | 提交工单并查看回复 |

重置订阅链接后，客户端中的旧链接需同步更新。

## 使用流程

1. 使用邮箱注册账号，完成验证后进入用户中心。
2. 比较流量与有效期，核对优惠、订单状态与应付金额。
3. 在总览复制订阅链接，按设备教程导入客户端，并定期更新订阅。

## 注意事项

- 部分套餐的名称、周期与页面标价并不完全一致，应以结算页信息为准。
- 恶意公开订阅链接会被封禁，订阅信息不宜分享。
- 特殊商品不支持退款，购买前需阅读用户中心的具体条款。
- 工单中不要填写密码或完整订阅链接。
